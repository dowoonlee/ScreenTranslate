ScreenTranslate 0.2.2 개발용 프리릴리즈입니다.

- **한 화면 비교:** 원본과 번역 이미지가 표시 영역의 가로·세로 안에 모두 들어가도록 자동 축소합니다. 비교 이미지 영역에는 스크롤이 생기지 않습니다.
- **과도한 확대 방지:** 작은 캡처는 원본 크기 이상으로 확대하지 않습니다.
- 가로가 세로의 2.2배 이상인 캡처는 원본 위·번역 아래, 그 외에는 좌우 비교를 유지합니다.
- **시작 시 업데이트 확인:** 앱을 시작하면 백그라운드에서 서명된 업데이트 목록을 확인합니다. 최신 버전이면 창을 표시하지 않고 새 버전이 있을 때만 설치를 안내합니다.
- 다운로드한 업데이트 파일은 압축 해제 전에 서명을 검증합니다. 자동 설치와 시스템 프로파일 전송은 계속 꺼져 있습니다.

기존 사용자는 **업데이트 확인…**으로 이 버전을 설치할 수 있습니다. 0.2.2부터는 시작 시 자동 확인이 적용됩니다. 동일한 코드 서명 인증서를 유지하며 화면 기록 권한을 초기화하지 않습니다.

**Apple Developer ID 서명·공증이 없는 개발용 프리릴리즈**입니다. 최초 다운로드는 Gatekeeper에 의해 제한될 수 있습니다. 시스템 보안 설정을 끄는 방식은 권장하지 않습니다. API 키·개인 설정·캡처 데이터는 배포물에 포함하지 않습니다.
