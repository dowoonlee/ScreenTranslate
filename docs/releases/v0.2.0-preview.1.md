Swift 기반 macOS 영역 번역 앱의 첫 공개 개발 프리릴리즈입니다.

- ⌘⇧2 영역 선택, OpenAI / Claude 이미지 문맥 번역
- 원본과 한국어 합성 이미지 좌우 비교, 결과 창 항상 위에 표시
- 번역 완료 전에는 메뉴 막대에서만 대기
- 키체인 API 키 저장, 키 교체·삭제, Claude 워크스페이스 설정
- 고정 개발 서명 및 서명된 Sparkle 업데이트 확인·설치
- Apple Silicon / Intel Universal, macOS 13 이상

**개발용이며 Apple Developer ID 서명·공증은 제공하지 않습니다.** Gatekeeper가 다운로드 앱 실행을 제한할 수 있습니다. 일반 사용자용 공증 배포는 추후 제공합니다. 시스템 보안 설정을 끄는 것은 권장하지 않습니다.

API 키는 각 사용자가 직접 등록하며 선택 이미지와 OCR 텍스트가 해당 API 업체로 전송됩니다. 원본 글꼴·배경을 복원하는 이미지 생성 방식이 아니라 흰 배경 위에 한국어를 합성합니다.

업데이트는 메뉴 막대 또는 설정의 **업데이트 확인…**에서 실행합니다. API 키·스크린샷·개인 설정은 배포물에 포함하지 않습니다.
