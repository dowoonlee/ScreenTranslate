# 초기 보안 검토 — 2026-11-02

대상: ScreenTranslate 0.2.0 Preview 1의 Swift 코드, 의존성 설정, 빌드·패키징·서명 스크립트와 공개 예정 파일. 이 검토는 코드·구성 및 로컬 검증이며 독립 침투 테스트 또는 Apple 공증 심사를 대체하지 않습니다.

## 수정한 사항

| 영역 | 문제 | 적용한 보호 |
|---|---|---|
| API 키 UI | 저장 키를 설정에 다시 읽어 장시간 보관 | 존재 여부만 확인, 새 입력은 저장·창 닫힘·앱 비활성 시 제거, 삭제는 명시적 버튼 |
| API 키 수명 | 캡처 선택부터 요청까지 키를 보관 | 전송 직전에만 읽기 |
| 네트워크 | API 리다이렉트 처리에 대한 명시적 제한 없음 | 리다이렉트 거절, 공식 HTTPS 주소 고정, 기본 TLS 검증 유지 |
| 오류 처리 | 불명확한 오류 또는 민감한 응답의 노출 가능성 | 요청 비밀값·인식 원문·토큰 패턴 마스킹, 영구 로그에는 HTTP 코드만 기록 |
| 권한 유지 | ad-hoc 코드 해시가 빌드마다 변경 | 앱 전용 인증서 고정, 지정 요구사항이 식별자와 인증서를 사용함을 확인 |
| 배포 | 임의 개발 빌드를 정식으로 배포할 위험 | production은 Developer ID·공증·stapling·Gatekeeper 검증 필수, unsigned 배포 거부 |
| 업데이트 | 원격 다운로드 코드의 위조 위험 | Sparkle 고정 버전, Ed25519 파일 및 피드 서명, 압축 해제 전 확인, 서명 실패 만료 예외 없음 |
| 공개 저장소 | 로컬 파일·개인 설정·키 포함 위험 | 파일 제외 규칙, 명시적 패키징, Gitleaks 및 공개 파일 검사, 읽기 전용 CI |

## 수행한 검증

- Swift 자동 테스트 통과: OCR·이미지 합성, API 요청 구조, 응답·ID 검증, 오류 마스킹, 헤더 제어문자 거절, 결과 없는 창 표시 방지.
- arm64/x86_64 Universal 빌드와 번들 내부 코드 서명 검증 통과.
- 공개 예정 Git 파일과 실행 파일 문자열에 대한 Gitleaks 검사 통과.
- 앱에 API 키·개인 설정·캡처·개인키 파일을 포함하지 않는 번들 정책 검사 통과.
- 업데이트 ZIP과 피드의 정상 서명 검증 통과.
- ZIP 바이트를 변조한 음성 테스트에서 서명 검증 실패 확인.
- 피드의 버전 표시를 변조한 음성 테스트에서 서명 검증 실패 확인.
- 개인 업데이트 키는 내보내지 않았으며 GitHub/CI에 등록하지 않음.

## 남은 제한과 운영 전제

- 개발용 프리릴리즈에는 Apple 공증, Developer ID, Hardened Runtime, App Sandbox가 없습니다. Gatekeeper가 다운로드 앱 실행을 제한할 수 있습니다.
- 실제 Developer ID·notarytool 자격 증명이 없어 정식 공증 경로는 준비만 되어 있으며 실환경 검증은 미완료입니다.
- macOS 13과 Intel 실기기에서의 기능 검증은 하지 않았습니다. 두 아키텍처 빌드·최소 OS 메타데이터만 확인했습니다.
- 화면 캡처는 일시적으로 디스크에 저장되어 강제 종료 시 남을 수 있습니다. 같은 사용자 권한의 악성 프로세스, 메모리 덤프, 운영체제 침해까지 방어하지 않습니다.
- 상세 API 오류의 마스킹은 최선 노력이며 공급업체가 임의 형태로 반사한 모든 개인정보를 제거한다고 보장하지 않습니다. 민감한 캡처를 외부 API에 보낼지는 사용자가 판단해야 합니다.
- 최초 공개 릴리즈에는 이전 공개 버전이 없으므로 실제 사용자 설치본의 버전 간 업데이트는 다음 릴리즈에서 추가 검증해야 합니다. 서명된 피드·ZIP과 변조 거부는 로컬에서 검증했습니다.
- 업데이트 키와 고정 서명 키의 보존·복구, GitHub 계정 MFA와 접근 권한 관리는 배포자의 책임입니다.

검토 범위에서 공개를 차단할 실제 비밀값 노출은 발견하지 않았습니다. 이 결과는 보안 사고가 발생하지 않는다는 보증이 아닙니다.
